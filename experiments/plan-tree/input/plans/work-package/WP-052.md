# WP-052 — FWHM-scaled FA read windows

## Objective

Make the FA read region follow the measured line width while keeping a configurable
minimum, so the model sees the full line rather than a fixed Å slice.

## Planned work

- Add `feature_read_fwhm_factor` and `context_fwhm_factor` with a default of 1.5.
- Compute the single-feature half-width from the frozen FWHM (Å or km/s at the centre).
- Compute each doublet side from its own component's FWHM.
- Keep legacy fixed-read tools unchanged; they have no FWHM at read time.

## Decisions

- 2026-10-26 — The decision owner proposed two FWHM per side (four FWHM total, beyond the
  Gaussian 3σ extent) and asked that the existing JSON parameter become a minimum.
- The doublet window is asymmetric when the two components have different widths, matching
  the stated `λ1 − 2FWHM` to `λ2 + 2FWHM` rule.

## Completion

- Status: **done** (2026-10-26). Both windows are scaled, config examples carry the new
  factors, and the new tests pass.
