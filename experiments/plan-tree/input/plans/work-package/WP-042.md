# WP-042 — Retained graded-reasoning implementation

## Objective

Preserve the implementation completed under WP-012 without representing its
cancelled independent expert-defect assessment as a passed calibration gate.

## Planned work

- Identify the implementation evidence retained from WP-012.
- State the rating contract and the excluded scientific claim explicitly.
- Verify the existing evaluator and grade-contract tests.

## Decisions

- The decision owner cancelled WP-012's independent expert-severity assessment
  on 2026-10-16. The full boundary and accepted consequence are recorded in
  `_aiHumanInteract/plan/evaluations/wp012-calibration-cancellation-20261016.md`.
- This successor retains the already implemented artifact set; it does not
  replace expert labels with correctness/ECE measurements or relabel the old
  WP-012 acceptance as passed.

## Completion

- The existing fuzzy predicates, relation-aware evaluator and grade contract
  are retained. The three targeted offline modules passed **42 tests** on
  2026-10-16. Their scope is implementation and schema behavior, not human
  severity agreement.
- WP-012's original unmet validation remains visible on the superseded source.
  This package is complete under its narrower stated acceptance boundary.
