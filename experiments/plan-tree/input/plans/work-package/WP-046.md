# WP-046 — Accuracy-first comparison

## Objective

Determine whether the new graph action loop earns its extra complexity on real spectra.

## Planned work

- Freeze a representative comparison set and preserve independent labels separately.
- Replay offline traces and run both execution paths with explicit stochastic limits.
- Review every changed decision and action, including failures and null results.

## Decisions

- 2026-10-16 — Replaces the old fixed-prompt compatibility gate while retaining truth-label isolation, full model-facing context inspection and output-contract checks.

## Completion

- Planned after WP-045.
