# ST-011 — Batch prompt assembly

## Scope

Organize the existing batch model context from validated input through rendering, invocation, and trace. Keep stable methodology in stage instructions; render spectrum facts, ontology-derived parameters and previous-stage artifacts as labeled run data. Preserve the Redrock-only path and scientific output contracts.

## Sequence

1. `WP-025` defines the shared input, authority, and provenance contract.
2. `WP-026` applies that contract to active stage renderers, starting with Redrock SH.
3. `WP-027` verifies full model-facing context, downstream contracts, and representative behavior before release.
4. `WP-043` moves FA read-window arithmetic and SH missing-candidate Gaussian
   fitting into deterministic preprocessing without changing the existing CWT
   and Predicted Lines tables.

## Decisions

- The repository-local Python renderer remains an acceptable mechanism; adopting a hosted prompt service or a template framework is not an objective.
- Batch execution remains usable without an app or session checkpointer. `docs/architecture/prompt-context-review.md` governs the separate future app boundary.
- Provider-native structured output is an option only after testing support from the configured model service. Until then, preserve and validate existing artifacts.

## Completion

- WP-029 has documented and corrected FA/HS/RA prompt authority, runtime parameter rendering, and stage rule boundaries; see its 2026-10-13 review correction. This is partial implementation under ST-011.
- The shared typed prompt-input contract, full renderer migration, and model-facing provenance gate remain with WP-025/WP-026/WP-027. Representative FITS/LLM behavior comparison remains required before release.

## Superseded 2026-10-16

ST-013 replaces open fixed-pipeline renderer work with graph-selected context and action provenance. Completed WP-029 and WP-043 remain historical results; WP-025 to WP-027 are discontinued, not accepted.

See `_aiHumanInteract/plan/evaluations/agentic-graph-reasoning-pivot-20261016.md` for the decision and successor mapping.
