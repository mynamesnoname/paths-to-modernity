# MT-003 — Introduce adaptive and budgeted execution

## Scope

Reduce median and tail latency by matching model calls and audit depth to spectrum risk and ambiguity.

## Execution notes

The `ST-001` auditor-only NPZ work observed an intermediate run in which a
`NEEDS_REVISION` verdict arose from unrelated concerns while the planted missing
Lyα went undetected; the final retained run did identify it. The retained
`QSO_116` FITS result also conflicts with historical outcomes whose full
provenance is unavailable; every FITS fixture has only one retained source-exact
run and may vary. When designing risk-adaptive graph execution, evaluate
explicit escalation for ambiguous cases and for auditor findings that do not
address a specific high-risk claim. Preserve the
NPZ Stage B isolation boundary and compare defect-specific findings, not just
the overall verdict. These are evaluation targets, not an attribution of the
observed variation to a proven cause.

Update the front matter before implementation begins and attach concrete
completion evidence before marking this node `done`.

standard-mode tool budget too small for the six-hypothesis path; the budget
was revised and a five-fixture run completed. `ST-007` remains open for
live early-stop/escalation tests and performance evidence. Status is
`in_progress`.
