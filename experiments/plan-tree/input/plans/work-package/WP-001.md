### from "Open items"

- 2026-10-08 — **`QSO_116` has conflicting recorded outcomes.** The first measurement and the five-fixture pass both returned `QSO` at `z≈2.92`, `MEDIUM` (50 and 47 calls); the retained source-exact run returned `Unknown`, `LOW` (47 calls), on the same input (`sha256 90d6a98e…`). The earlier full records and their source/config fingerprints are not retained, so the cause cannot be verified; a controlled repeat is required before this baseline is used as a compatibility gate.
- 2026-10-08 — **No fixture has retained source-equivalent repeats.** All five carry exactly one retained run under `ST-001`'s provisional single-run comparison policy, so none is established as stable and a repeated-run vote would need new per-run evidence and an agreed stopping rule.
- 2026-10-08 — **H6 acceptance was unstable.** Earlier audit notes flagged C III] `NOT_FOUND` at its predicted position — which the knowledge base lists as fatal for a Type 1 QSO — while still accepting H6 at `MEDIUM`; the retained run excluded H6 and synthesis accepted "HNone". Repeat-run verification is still required before the risk-adaptive execution proposed for `MT-003` can rely on this signal.
- 2026-10-08 — **Representative latency is unmeasured.** `wall_time_s` is valid only under the recorded deviation (`rrdesi_mp_override: "1"`, `/dev/shm` unwritable); it must not be quoted as default-configuration latency. A representative figure needs re-measurement where redrock keeps its default process count (see the last Evidence item).
- 2026-10-08 — **Prompt caching is unverified.** No cache setting exists in `core/llm.py`, `core/config/*.py` or `.env.example`, and actual prefix overlap and endpoint caching support have not been measured, so baseline token volume must not be read as baseline cost.
- 2026-10-08 — **Driver equivalence is unpinned.** `scripts/run_baseline.py` replicates the inner loop of `scripts/main.py` rather than calling it, and the two differ deliberately (the baseline records failures instead of raising and builds one orchestrator per fixture); no test pins that equivalence, so a change to `main.py` could silently diverge from the frozen baseline.
- 2026-10-08 — **The feature-audit prompt payload is unmeasured.** The mandated batched `read_spectrum_region` reads coincide with measured single-step context jumps of +70,463 tokens (`QSO_4`) and +81,736 (`ELG_6`); how much of that increment is raw arrays is not measured, and removing it would bound the achievable peak reduction at 18.0–40.4 %, because the synthesis call then becomes the peak. Whether local significance moves into deterministic code is still open under `MT-001`.
- 2026-10-08 — **The orchestration boundary is undecided.** The six parallel hypothesis sessions are already context-isolated (prompt sizes oscillate between 9.2 k and 24.6 k on `QSO_4`), so a subagent harness would buy orchestration freedom rather than peak-window relief; whether that is the intended benefit, and whether it belongs to `MT-003`, is not recorded.
