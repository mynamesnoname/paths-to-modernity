# REQ-001 — Explainable routing

Operators need to understand why an automated router selected a slow path, but
the initial request did not say whether the plan should also own remediation.

## Boundary decision

- Inside: record and reproduce routing decisions.
- Outside: automatically repair or retry a slow route.
- Interface: the existing operator recovery procedure remains unchanged.
- Decision: own detection and explanation only.
- Accepted cost: recovery remains manual.
- Decision-maker: operations lead.
