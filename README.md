# Paths to Modernity

A skill for clarifying intent with people, defining scope and outcomes,
structuring complex plans, and comparing alternatives. The name retains the
project's origins; using the skill requires no art vocabulary.

Start with [SKILL.md](SKILL.md). The optional
[Plan Graph](references/plan-graph.md) implementation connects Markdown source
plans to implementation and evidence through categorized links, and generates
JSON, Markdown, and Canvas views.

The [worked example](assets/plan-graph/example/README.md) shows how the pieces
fit together. The files under `assets/plan-graph/` are an installation bundle.
`agents/openai.yaml` provides UI metadata.

For skill maintenance and verification, follow [AGENTS.md](AGENTS.md).
