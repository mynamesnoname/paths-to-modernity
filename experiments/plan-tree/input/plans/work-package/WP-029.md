## Open questions and pending items

- **Not done here, and stated as gaps in the RA document rather than silently fixed:** no rule is declared `fatal_eligible`, so the deterministic cap cannot fire; the shared per-line detectability layer is still not wired into the auditor adapter; RA's resolved-rating provenance is still memory-only; seven of eight auditor rules encode their contradiction as `pass` + negative polarity while the cap requires `outcome == "fail"`. Declaring fatal eligibility changes ratings and needs the decision owner, so this package left the registry at `fatal_eligible=false`.

## Completion

- `docs/graphs/FA/FA规则.md`, `docs/graphs/HS/HS规则.md`, and `docs/graphs/RA/RA规则.md` now state the same three-way authority split as `docs/graphs/SH/SH规则.md`; the SH document itself was corrected where it attributed registry-rendered numbers to the prompt and the rule call to the orchestrator.
- The FA, HS, and RA prompts contain no numeric threshold. `prompt_audit.audit()` reports **38 statements and 0 problems**, down from 84 statements; the removed 46 were all prompt-side restatements. The remaining 38 are the KB corpus, which is unchanged.
- New `render_registry_parameters()` in `harness/tools.py` renders only the groups a caller asks for (memberships, edge zones, doublet expectations, skylines, index bands, auditor class bounds) from their owning records. The FA message receives memberships, edge zones, doublet expectations and skylines plus an explicit read-window block; HS receives memberships, edge zones, skylines and the Dn4000 band; RA receives memberships, edge zones, doublet expectations, skylines and the audited class bounds.
- Numeric ownership closed in four places: doublet `ratio_window` became a registry field with the five records populated; `rule:formal-dn4000-interpretation` now owns the 1.6/1.3 break bands that `HA.build_dn4000_lookup` reads through `query.dn4000_interpretation_bands()`; FA's blue-edge/OH-zone flags read the zone rules through `_zone_bound()`; the audit's canonical-value reader understands `ratio_window` and `rhs_high`.
- Cross-stage reconciliation: the report-writer prompt now reads `spectrum_issues` (the field RA emits) with `key_issues` as fallback; RA's prompt and user message use the same field name; an unrecognised `calibrated_confidence` degrades to an unavailable rating with `ra_rating_rejected` recorded instead of raising; `scripts/main.py` imports the SelfEvolve batch helpers from `utils.SE`, so `SELF_EVOLVE=true` no longer fails at the final flush; the `AnalysisAuditor` ↔ `hypothesis_synthesis` import cycle is resolved by a lazy import, so every import order now works.
- Line anchors: `AnalysisAuditor.py` is cited by stable symbol names, not line numbers, because it moved during this package.
