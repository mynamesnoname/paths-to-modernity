# WP-053 — Unified run contract

## Objective

Give the demo and the CLI the same input selection, run directory and index envelope,
so a run can be inspected or compared without knowing which entry point produced it.

## Planned work

- Extract `run_contract.py`: sample-name validation, new run directory, FIBERMAP truth,
  HS row summary and atomic `index.json` writes.
- Move `demo.py` onto those helpers.
- Rewrite `main.py` around `--file-name` / `--samples` / `--all`, a run directory, a
  per-run index and a preflight.
- Keep the legacy `in_brief.csv`, but inside the run directory.

## Decisions

- 2026-10-28 — The demo layout is the standard; the CLI adopts it for both workflows.
  Input names are stems and are validated; absolute paths and separators are rejected.

## Completion

- Status: **done** (2026-10-28). Live graph BGS_2 run through the new CLI wrote a fresh run
  directory with `index.json` and `BGS_2/` and completed HS-stage (LRG/BGS, z=0.159146);
  a first attempt failed on a transient provider `BadRequestError` and succeeded on retry.
  Preflight and the contract tests pass.
