# WP-047 — Vote bands and materialized abstention

## Objective

Make the vote distribution an explicit, testable part of the FA contract: assured bands at
the edges, low-reference leaning bands in the middle, and review as the consumer of the
middle. Keep the per-seat prompt binary so that disagreement remains observable.

## Planned work

- Declare the four bands for odd totals `N >= 5` (`<=25%` N assured, `25-50%` leaning N,
  `50-75%` leaning Y, `>=75%` Y assured) in one code-owned place, with inclusive/exclusive
  boundary tests.
- Decide and implement the `N = 3` mapping: which bands a three-seat run can report, and
  whether `2/3` is "leaning" or a review trigger.
- Emit band membership in the feature state and in the report artifact, without changing the
  per-seat prompts.
- Define the review-queue contract: which rows a reviewer receives and what the reviewer is
  asked to decide (feature reality vs pair corroboration).
- Re-run the 2026-10-19 label study against the declared rules and compare with
  `fa-vote-bands-20261022.md`.

## Decisions

- 2026-10-22 — The decision owner defined the bands as `[0,25%]`, `(25%,50%)`, `(50%,75%)`,
  `[75%,100%]` on `Y/Total`, for totals of five or more, and expects the middle two bands to
  be the focus of review rather than decision-grade output.
- 2026-10-22 — Abstention is materialized by the vote split, not by a third answer. The
  decision owner's stated risk is that an explicit abstain option would make the model
  abstain by default; prompts therefore stay binary.
- 2026-10-22 — Labels from the 2026-10-19 run show agreement is informative (45/45) and that
  the 2-of-3 majority is not measurably better than one seat on disputed features (8/14 vs
  22/42). The bands should therefore drive triage, not a majority verdict.
- 2026-10-22 — Doublet votes are scored on pair corroboration; a real but unresolved blend is
  negative for the doublet question. This affects both the labels and the review copy.

## Completion

Not started. The requirement, the label study and this work package are recorded; the band
declaration, runtime mapping and review queue remain to be implemented.
