# REQ-001 — Modernist plan architecture experiment

## Raw requirement

Explore whether the development of modern painting can inform the plan
architecture. The proposed transformations are:

- distill color and skeleton from long requirement narratives;
- compose plans through structure and blocks;
- retain an impression or vibe that cannot initially be reduced to acceptance tests;
- reconstruct the same object from multiple perspectives;
- normalize the object into a quiet geometric core and produce controlled variants.

The experiment should be concrete enough to use in this repository rather than
remaining a conceptual analogy.

## Distilled reading

The request is not for artist-themed field names. It asks whether a plan can
retain five properties at once: traceability to raw intent, structural clarity,
experiential direction, perspectival plurality, and comparable alternatives.

## Invariants

- Markdown plan nodes remain the source of truth.
- LT → MT → ST → WP remains the decomposition hierarchy.
- Generated views cannot become competing editable sources.
- Subjective qualities cannot replace objective acceptance criteria.
- Normalization cannot erase provenance or rejected alternatives.

## Open questions

- How much interpretive metadata belongs in canonical node front matter?
- Should variants be full plan nodes or linked documents?
- When is a rejected variant resolved enough for its ancestor to complete?
