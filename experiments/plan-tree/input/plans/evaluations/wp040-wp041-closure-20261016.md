structured-summary keyword, and a CLI path that treated a missing report as
success. These were repaired and covered by focused regressions. The preceding

for an unfinished tool turn was added before `r7`, which completed. The `r7`

output directories.

## Limits

The per-value manifest covers values registered by the prompt builders. It is
not a proof that every number typed into free prose has an owner. The separate
rendered-number audit reports possible omissions but includes observational
measurement false positives; it remains a review report. Model-generated text
is outside deterministic prompt re-rendering. This run proves artifact and
authority wiring for one real spectrum, not all scientific outcomes or held-out
calibration. Redrock hashes are recorded before execution and are not enforced.
