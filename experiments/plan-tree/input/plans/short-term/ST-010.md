# ST-010 — Migrate active spectral reasoning to ontology governed knowledge

## Scope

Inventory active scientific facts and rules, formalize the rules, then route
runtime consumers through one registry. Preserve narrative explanations and
existing output contracts. Offline fixtures provide the first ontology-specific
compatibility gate; `ST-004` owns the real FITS/Redrock/LLM graph compatibility
decision, and held-out calibration remains in `WP-012`.

## Sequence

1. `WP-021` maps knowledge uses and assigns source ownership.
2. `WP-022` defines typed constraints and rule semantics.
3. `ST-004` records and adjudicates the graph compatibility comparison.
4. `WP-023` integrates rules into active paths and records offline parity.
5. `WP-024` retires the alternate Nomad/BFM path and makes the Redrock SH
   prompt consume runtime ontology context (REQ-005).
6. `WP-028` replaces the blanket ultraviolet anchor veto with a ranked,
   caveated fallback policy (REQ-007).
