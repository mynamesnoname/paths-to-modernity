# MT-004 — Evidence-driven graph reasoning

## Scope

Design the live investigation graph from SH reasoning questions, node lifecycle and revisitable judgments. Consume primary scientific data and validated tool results through explicit interfaces. Existing ontology records may be queried through a reviewed adapter; the old Evidence Graph is not an input contract or implementation base. First establish a bounded SH pilot; later expansion depends on actual scientific outcomes, not a graph database migration.

## Decisions

- 2026-10-16 — The user prioritized reasoning accuracy over the remaining latency-first MT-003 gate. The plan transition and retained runtime obligations are recorded in the linked evaluation.
- WP-037 continues its distinct real graph-chain acceptance. The 16-spectrum legacy challenge is retrospective diagnostic input, not independent validation.
- 2026-10-16 — Superseded preparation wording that treated the old Evidence Graph as a provenance substrate. The decision owner excluded it as the new graph's foundation; neither its schema nor its projected artifact is a required runtime dependency. The new implementation lives under `src/FORMA/agentic_graph/`; the fixed pipeline remains runnable for comparison.
