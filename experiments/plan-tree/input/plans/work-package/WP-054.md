# WP-054 — METADATA VI labels

## Objective

Read VI truth from either supported FITS table and keep galaxy type comparison
meaningful when the files only say `GALAXY`.

## Planned work

- Add a shared reader for `FIBERMAP`/`METADATA` labels and `TARGETID`.
- Map VI types to candidate sets, treating `GALAXY` as any galaxy branch.
- Point the contract, evidence builder, baseline script, historical runner and
  calibration selectors at the shared reader.
- Update preflight/docs/tests for the new label values.

## Decisions

- 2026-10-28 — The file update is authoritative: METADATA is the new location and
  `GALAXY` is expected. No subtyped galaxy label is invented.

## Completion

- Status: **done** (2026-10-28). All readers use the shared helper; preflight and
  both test suites pass; full five-spectrum execution was not repeated.
