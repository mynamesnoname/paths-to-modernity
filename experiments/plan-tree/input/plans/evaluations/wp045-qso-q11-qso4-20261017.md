# WP-045 — QSO Q11 报告节点实测（2026-10-17）

## 实施与边界

`qso_report.py` 从当前 branch 的 Q1 cleaned view、Q2 Type 2 出口或 Q9→Q10 Type 1 出口建立模型可见的规范上下文。执行前验证节点身份、原产物摘要、SH×FA 投影与终点映射；模型调用期间若状态变化也拒绝提交。模型只写六节归纳文字，逐线数值表由程序插入；红移、路径状态、候选类型、初判类型和终点引用在提交前严格核对。`report.md`、`context.json`、`session.md`、`node.json` 位于独立执行目录，登记 SHA-256 和 branch event。回退分支可复用已继承的 Q1/Q2，生成新报告而不覆盖旧报告。

Q2 的直接出口可通过 `run_qso_entry_through_report` 接到 Q11。已有轨迹可用 `evaluation/agentic_graph/run_qso_reports.py` 一次追加一个 Q11 报告；它不重跑 FITS、Redrock、SH 或 FA。Q4–Q10 的正式执行器尚不存在，因此真实 Type 1 路径的 Q11 报告未实测；合成 Q9→Q10 未决路径用于验证 Q11 不把未决提升为存活。
