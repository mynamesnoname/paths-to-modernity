# WP-043 — Deterministic FA reads and SH prefit

## Objective

Let code calculate configured read windows and mechanically run targeted fits;
let the agents judge whether the resulting candidate features identify lines.

## Planned work

- Add a centre-based FA read tool while retaining a free-range tool for edge
  zones, composite profiles, and Lyα forest checks.
- Before each SH model call, compare predicted positions with local CWT
  candidates, run targeted single or registered doublet fits where absent, and
  archive every attempted fit outcome.
- Keep the existing CWT and Predicted Lines tables unchanged. Add a fit-attempt
  section below the latter, with failed attempts represented by status and
  reason rather than invented measurements.
- Feed precomputed successful measurements to the same SH provenance validator
  used for agent-invoked fit tools.

## Decisions

- 2026-10-16 — User requested a pushed recovery commit before implementation;
  `28292c7` on `origin/feature/evidence-graph` is that checkpoint.
- The existing verification z-window is too broad to define a local CWT match.
  Use the registered offset-quality boundary as the local limit and require the
  candidate's implied redshift to lie within the verification window.
- Fit success is a measurement attempt, not automatic line identification.

## Completion

- FA read tool, SH preprocessing and provenance integration are implemented.
  Offline, isolated real-model, and full FITS evidence is recorded in the linked
  evaluation. QSO_4 passed the complete pipeline, including the 36-row FA read
  contract. A separate H4 model run checked the final blend provenance guard.
